# CONTEXT — agora（特性级术语表）

> 本文件为 `agora` 特性的术语表；角色与领域词以此为准（下游 `specify`/`clarify`/`design` 读取）。与 `docs/features/brainstorm/CONTEXT.md` 术语重叠处，本文件为本特性（引擎层）的规范。

## Glossary

**角色**

- **场景作者（Scenario Author）** — 用声明式配置定义一个场景的人；agora 的核心用户。只写配置、不写引擎代码（除非经「扩展区」）。勿与「发起人」混淆：场景作者定义「场景长什么样」，发起人用它跑一场。
- **发起人（Host）** — 提供运行时值（主题等）并启动/停止/观察一场会话的人或系统。沿用 brainstorm 的 Host：发起人本身不发言。
- **角色（Role / 参与者）** — 场景里定义、会在共享桌面上发言的 AI 角色（人设、正反方、裁判等）。某个角色可被指定为「选人者」或「裁判」。勿与「场景作者」混淆：角色是会内的发言者，场景作者是会外的定义者。
- **选人者（Selector role）** — 被配置为「决定下一位发言者」的角色。勿与「裁判」混淆：选人者决定「谁下一个说」，裁判决定「是不是该结束了」。
- **裁判（Judge role）** — 被配置为「判定是否收敛」的角色。勿与「选人者」混淆（在 brainstorm 里两者曾由同一个「主持人」兼任，本特性将其拆开）。
- **扩展者（Extension Author）** — 经「扩展区」为引擎写自定义能力代码的人。与场景作者区分：扩展者写代码、场景作者写配置。
- **观察者（Observer）** — 订阅进度事件、只读不发言的角色。沿用 brainstorm 定义。

**领域词**

- **引擎（Engine / agora）** — 无语义的接力协作内核：只做「按序接力 + 共享转录 + 判停 + 持久化恢复」，不懂「头脑风暴」或「辩论」这类场景语义。
- **原子（Atom）** — 引擎收敛的最小能力单元（产出 / 选人 / 判停 / 存储 / 摘要）。「新能力 = 新原子 = 写代码」。
- **场景（Scenario）** — 引擎上的一类应用（头脑风暴 / 辩论 / 面试），= 一份声明式配置 + 运行时值。
- **菜单 / 闭集（Closed menu）** — 标准原子的固定集合；场景作者从菜单里组合。菜单外 = 走扩展区。
- **扩展区（Extension zone）** — 受控的自定义代码接入点，独立于标准菜单、接口风格可自定义、不承诺稳定 ABI（本轮）。
- **共享桌面 / 转录（Shared transcript）** — 全员可见、按序累积、标注发言者的发言记录。
- **产出（Producer）** — 生成一条发言的原子：模板 + 上下文注入 + 生成 + 解析。
- **选人（Select）** — 决定下一位发言者的原子（固定轮转 / 让某角色挑）。
- **判停（Stop）** — 判定会话是否结束的原子（固定条数 / 让某角色裁决 / 手动）。
- **存储（Store）** — 持久化共享转录与会话/角色状态的原子。
- **私有状态（Private state）** — 角色跨轮携带的私有笔记/草稿，他人不可见；可由「摘要」填充。
- **摘要（Summary）** — 把共享桌面内容压缩进角色私有状态的原子能力（维持角色的跨轮连续性）。
