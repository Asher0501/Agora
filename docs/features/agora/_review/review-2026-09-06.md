## Findings（全部决议 Fix now）

### Stage 1 — blocking AC gaps

1. **AC-06 未实现** — `agora/errors.py:36` 定义了 `turn_already_produced` 却从不 raise；`agora/relay.py` 无「同 turn 二次产出」守卫，无测试断言该不变量。当前仅由单线程线性循环 + 原子追加「空洞地」成立（T7 DoD 声称有 AC-06 测试，未兑现）。**Fix:** 产出前检查当前 turn 是否已落桌，已落桌则 raise `TURN_ALREADY_PRODUCED`；补一条同 turn 二次产出被拒的测试。
2. **AC-11 停止握手断裂** — `agora/session.py:85-94` 先写 `stop_requested=True`，随后两行又用不含该标志的 `{"status":"stopped",...}` 整体覆盖，运行中的 relay 轮询的 `stop_requested` 标志被抹掉；`agora/relay.py:85-126` 循环每次迭代也不检查 `status=="stopped"`。实测（gated-LLM 探针）：产出在途时调 `stop_run` 不会取消它——放行后在途发言仍落桌、relay 永不终止。测试（`test_stop.py`、`test_lifecycle.py`）只在无 relay、无在途产出的隔离态下调 `stop_run`，未断言 AC 的可观测结果。**Fix:** `stop_run` 最终状态写入保留 `stop_requested`；relay 在 `status=="stopped"` 时 break；补一条「relay 运行中 + 并发 `stop_run` + gated LLM → 在途发言不落桌」的测试。
3. **AC-14 扩展区未接通** — `agora/extension.py:15-22` 的 `register_capability`/`known_capabilities` 只对裸 `dict` 有效，而 relay 消费的是 `Registry` 对象（读 `registry.capabilities`），实测 `register_capability(build_registry(), "x", cap)` 抛 `TypeError`。AC-14 的「该能力被场景使用 → 生效」仅有裸 dict 单测 + 配置期接受，无集成/e2e 测试（test-plan 行 `extension-capability-takes-effect-menu-untouched` 未覆盖）。**Fix:** 让 `register_capability`/`known_capabilities` 作用于 `Registry.capabilities`（或同时接受二者）；补一条「场景引用已注册自定义 selector 并跑通 relay」的 e2e。
4. **AC-18 `observe` 命令不符契约** — `agora/cli/__init__.py:135-138` 读 `repository.read_events(run_id)`（持久化的系统观测事件 `invalid_choice`/`verdict_parse_failure`），而 `contracts/cli.md` §2.4 / AC-18 / Flow 11 契约「订阅并流式打印本会话进度事件（回合开始/发言落桌/收敛/停止）」。进度事件是进程内 pub-sub、不持久化（`data-model.md:165`），独立 `observe` 进程永远打印不到；对 `brainstorm.yaml` 场景 events namespace 恒空 → observe 打印空。无测试断言 observe 打印任何东西。**Fix:** 让 `observe` 同进程挂 `Observer` 到运行中的 relay，或重写 `cli.md` 使其匹配持久化事件流。

### Stage 1 — contract/doc drift

5. **`SummaryConfig` 形状漂移** — `agora/types.py:47-52` 实现并校验 `role/key/window`，但 `contracts/public-api.md:76-80` 仍标 `# unresolved`（opaque）、`data-model.md:95` 仍记 `summary: {...}|null`。**Fix:** 把 `public-api.md` §2.1 与 `data-model.md` 更新为已批准的 `role/key/window` 形状。
6. **错误码计数漂移** — `contracts/public-api.md:27` §1 写「8 个错误码」，§3 列 9 个、`agora/errors.py` 注册 9 个（`test_domain.py:92` 断言 9）。**Fix:** 把 §1 改为 9。
7. **`sad.md` 仍用 `session_id`** — `sad.md:60,116,250,413,420,434,450,483-486` 仍写 `session_id`，而 data-model/contracts/代码统一用 `run_id`（api-sync C-1 预标注，本 diff 内未收口）。**Fix:** 扫 `sad.md` §2/§6/§8 到 `run_id`。

### Stage 2 — correctness/safety

8. **裁判解析失败绕过 `max` 硬上限 → 无限运行** — `agora/atoms.py:211-213` 在解析失败时先返回 `StopDecision(stop=False)`，跳过了 `:218-221` 的 cap 检查。AC-10b 承诺的兜底被绕过；持久返回垃圾的裁判会让 run 超过 `max` 并空转。**Fix:** cap 判定独立于（先于）解析失败分支——达上限时即便裁判垃圾也返回 `cap_unconverged`。
9. **`stop.max` 非必填 → 无上限接力** — `agora/config/validator.py:91-96` 仅在 `max is not None` 时查正性；`agora/atoms.py:189-193` 的 `FixedRoundsTerminator` 在 `max=None` 时恒 `stop=False`。`stop:{type:fixed_rounds}`（或 `llm_verdict` 无 cap）可通过加载且 round-robin 下永不终止。**Fix:** `stop.type ∈ {fixed_rounds, llm_verdict}` 时要求正的 `stop.max`（spec 承诺的通用兜底）。
10. **配置标量类型未校验 → 裸 `TypeError`/`ValueError`** — `agora/config/validator.py:92`（`stop.max` 为字符串时 `<= 0` 抛 `TypeError`）、`agora/config/schema.py:86,98`（`int("abc")` → `ValueError`）。实测 `parse_config(stop.max="12")` → `TypeError`、`window="abc"` → `ValueError`，均以非 `DomainError` 逃逸，违背 QG-1「非法配置 100% 加载时拒绝 + 可读原因」。**Fix:** 在 `schema.py`/`validator.py` 做整型字段类型检查/强转，非法时 raise `DomainError`。
11. **`weave_agent_sdk` 运行时依赖未声明/未固定版本** — `pyproject.toml:11-13` 仅列 `pyyaml`，而 `agora/adapter/repository.py:21`、`adapter/llm.py:12` 运行时 import `weave_agent_sdk`。全新 `pip install .` 后 `import agora.cli` 抛 `ModuleNotFoundError`（测试绿只因环境装了 editable `weave-agent-sdk 0.2.0`，且与 SAD §2 文档的 0.1.0 不一致）。**Fix:** `[project].dependencies` 声明（并固定）`weave-agent-sdk`；对齐 SAD §2 版本与 adapter 实际 import 名。

### Stage 2 — test gaps

12. **OQ4 确定性回退无端到端测试** — `agora/relay.py:107-111` 的 `decision.parse_failure → append_event("verdict_parse_failure") + 继续` 路径，所有裁判测试都喂可解析输出（`test_loop.py:92-110`、`test_moderator.py:59-66`、`test_atoms.py:136-148`），事件写与「继续到 cap」均未断言。**Fix:** 加一条 relay 级测试：不可解析裁判回复 → 断言 `verdict_parse_failure` 事件且 run 走到 `cap_unconverged`。
13. **NFR 延迟/并发阈值烟雾化放宽 10×** — `tests/test_nfr.py:94-95,108-109` 断言 p95 ≤1000ms/500ms（spec §6 为 100ms/50ms）；`test_five_concurrent_runs_isolated`（`:76-83`）只断言转录长度 + 隔离，未测 QG-5「并发 vs 单会话基线 ≤2×」比率。**Fix:** 记录单会话基线 + 并发 p95 并断言比率，或将测试声明收窄为「smoke」。
14. **零 weave 依赖测试只扫 3 个模块** — `tests/test_domain.py:156-162` 仅查 `types.py`/`errors.py`/`namespaces.py`，而 `atoms.py`/`relay.py`/`session.py`/`config/*`/`extension.py` 同属领域层却未守护（今日代码干净，`adapter/` 是唯一 importer——但守卫窄于其所声不变量）。**Fix:** 扫所有 `agora/**` 模块（除 `agora/adapter/`）。
