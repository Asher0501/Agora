## 本轮新发现（6 项，全部决议 Fix now）

### Stage 1

1. **F1 — 校验通过的配置仍可运行时裸崩溃（prompt 占位符不被注入）** — `agora/config/validator.py:66-71,93-115`；`agora/atoms.py:169-175,207-211`；`agora/relay.py:206`；AC: n/a（击穿 QG-1「非法配置 100% 加载时拒绝」）。`verdict`/`pick_next` 角色的 inject 字段只要 ∈ `_KNOWN_FIELDS` 即过加载校验，但 LlmPickSelector/LlmVerdictTerminator 的 render 上下文只有 `{name, history}`，relay 也只给 `summary.role` 注入 summary——裁判/选人者 prompt 引用 `{topic}`/`{stance}`/`{summary.key}`、或非 summary 角色 free_text 引用 summary key 时 `str.format` 抛裸 `KeyError`。
   **决议（Fix now，用户方针）**：不给校验器引入大量占位符白名单责任；改为设计渲染机制，使其能输出正确的 prompt（在渲染层保证 prompt 引用的字段可用 / 安全格式化，缺字段时给出可读 DomainError 而非裸 `KeyError`）。与 [[engine-vs-prompt-boundary]] 一致——引擎只保证机制正确，不堆业务语义校验。

2. **F2 — Terminator 协议签名 sync/async 漂移** — `docs/features/agora/contracts/public-api.md:225` 写同步 `def should_stop`，代码 `agora/atoms.py:51` 为 `async def`、relay `await` 调用（`agora/relay.py:102`）。照契约实现自定义 terminator 的 SDK 消费方会拿到未 await 协程/`TypeError`。
   **决议（Fix now）**：`public-api.md` §4 改为 `async def should_stop`。

3. **F3 — api-sync-report 过时 + 3 个 config 错误码未登记** — `contracts/api-sync-report.md:30,95,103-115` 仍称 sad.md 残留 `session_id`、SummaryConfig 无字段形状（实际均已收口）；`agora/errors.py:39-41` 的 `reserved_agent_id`/`invalid_placeholder`/`invalid_config` 未入 `public-api.md` §3 表，「9 码无游离」不再准确。
   **决议（Fix now）**：更新 api-sync-report 为已收口状态（或标注快照日期），public-api §3 表补登记 3 个 config 码。

4. **F4 — test-plan 两行 CLI e2e 成功路径无实现测试** — `test-plan.md:51,57`（`stop-via-cli-stop` / `resume-via-cli-resume`）在 `test_cli.py:64-79` 只测不存在 run 退出 1，成功语义仅在库级钉住（`test_stop.py:98`、`test_integration.py:73`）。
   **决议（Fix now）**：补跨进程共享临时 SQLite DB 的 CLI 成功用例（`agora stop <live run>` 并发停 + `agora resume` 续跑）。

### Stage 2

5. **F5 — 配置结构形状非法逃逸裸 `AttributeError`/`TypeError`** — `agora/config/schema.py:48-56,103-135` `_parse_role/_parse_select/_parse_stop/_parse_summary` 直接 `raw.get(...)`；`roles` 为标量/`null`/mapping、role 条目非 dict、或 select/stop/summary 非 mapping 时裸崩。T21 只修了标量值，未修结构形状。
   **决议（Fix now，轻量）**：各 parse 入口加 `isinstance(raw, dict)` 守卫，`_build_scenario` 校验 `roles` 为 list 且逐条 dict，违者 `raise DomainError(INVALID_CONFIG,...)`（不堆额外规则）；补 3-4 条结构形状拒绝测试。

6. **F6 — `llm_verdict` 缺 judge / `llm_pick` 缺 role 可加载、运行到 relay 才失败（半创建会话）** — `agora/config/validator.py:74,83` 仅在 judge/role 已存在时做引用校验；缺 judge/role 时 LOADS OK，relay `_find_role(scenario.roles, None)`（`agora/relay.py:169,184`）才抛 `INVALID_CONFIG`，此时 `create_run` 已落盘。
   **决议（Fix now，轻量）**：`stop.type=="llm_verdict"` 且 `stop.judge` 为空、`select.type=="llm_pick"` 且 `select.role` 为空时在 validator 里 `raise DomainError(INVALID_CONFIG,...)`；补两条加载时拒绝测试。
