# CONTEXT — brainstorm（特性级术语表）

> 本文件为 `brainstorm` 特性的术语表；角色与领域词以此为准（下游 `specify`/`clarify`/`design` 读取）。

## Glossary

**角色**

- **发起人（Host）** — 提供主题、选定人设与配置、启动/停止会话的人或系统。勿与「参与者」混淆：发起人本身不发言。
- **参与者（Persona / 人设）** — 具名、带角色描述的 AI 角色，按序在共享桌面上发言。勿与「路由者」混淆：普通参与者不决定发言顺序。
- **路由者（Moderator / 主持人人设）** — 可选的参与者型角色，在每次发言后的路由时点决定下一位发言者并判断收敛；其余与人设无异，只是调度时机特殊。勿与「发起人」混淆：路由者是会话内的 AI 角色，发起人是会外的启动者。

**未来可衍生的分支角色（当前迭代不启用，作为扩展方向保留）**

- **观察者（Observer）** — 只读角色，读取共享桌面转录；未来 Web 论坛等界面的典型角色。勿与「发起人」混淆：发起人能启动/停止，观察者只能读。

**领域词**

- **主题（Topic）** — 头脑风暴要讨论的问题或命题。
- **共享桌面（Shared Table）** — 会话内所有发言按序累积、对所有参与者可见的讨论记录。
- **发言（Speech / Utterance）** — 某一参与者对主题与历史发言的一次贡献，落到桌面并标注发言者。
- **会话（Session）** — 一次头脑风暴实例，含主题、人设名单、共享桌面与停止条件。
- **轮（Round）** — 固定轮转模式下，所有人设各发言一次构成的一轮。
- **停止条件（Stop Condition）** — 会话结束的判据（固定轮数 / 收敛判定 / 手动停止）。
- **收敛（Convergence）** — 讨论被判定为「已达成结论」的状态；本特性由路由者宣告收敛，或由固定轮数/手动停止结束。勿与「停止」混淆：收敛只是停止的一种判据。
