## Fix list（交回 `implement`）

1. **CLI e2e + 可裁决路由 double（F3，AC-07/08/10）**：给 CLI 装配路径注入一个确定性、能输出 `NEXT:`/`CONVERGE:` 的路由 double；补 `test_cli.py` 的 moderator 收敛 e2e（覆盖 AC-07/08/10）。

5. **路由者私有记忆接线（F7）**：给 `SchedulerContext` 传入 `private_memory`（或路由者 `persona_id`），`ModeratorScheduler` 构造 `RoleContext` 时带上。
6. **停止观测事件（F8）**：`stop_session` 直接结束路径补发 `session.stopped`。
7. **invalid_choice 落库断言（F9）**：moderator 集成测试补一条「无效选择后 `read_events` 含 `type=invalid_choice`」断言。
8. **data-model 命名回改（F10）**：`data-model.md` §System records 落点改为 `brainstorm:{session_id}:events:stream`，并注明 weave namespace 约束。
